## 手机远程控制

通过 Discord 或 Telegram 给 agent 发消息，让它在我的个人电脑上操作。

设想的用法：

- **随手投递：** 在地铁上看到一个 job description，直接发给 agent，由它帮我投递。
- **每日定时：** 每天在电脑前自动执行一轮，处理岗位库里合适的岗位。

执行前要决定的问题：

- **最后一步怎么确认：** 现在的流程是我亲手提交。如果在手机上操作，需要决定是发摘要给我确认，还是回到电脑前再提交。
- **CAPTCHA 怎么处理：** agent 暂停时要通知到手机，并决定我在手机上怎么接手，还是等回到电脑前处理。
- **电脑在线：** agent 运行在个人电脑上，所以电脑要保持开机和联网。
- **消息来源：** 只接受我本人账号发来的消息，其他人发来的内容不能触发投递。
